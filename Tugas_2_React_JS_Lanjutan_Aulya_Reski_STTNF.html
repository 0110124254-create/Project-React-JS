1. Ringkasan Tugas 2

Melanjutkan Tugas 1 sebelumnya, pada Tugas 2 React JS Lanjutan ini mahasiswa diinstruksikan untuk melengkapi siklus penuh operasi CRUD dengan mengimplementasikan fitur Update (mengubah data yang sudah ada) dan Delete (menghapus data) untuk bagian Genre dan Author (Penulis) pada tampilan antarmuka Admin.

Implementasi fitur Update menggunakan metode HTTP PUT via library Axios dengan form yang terisi data awal secara otomatis (*pre-filled*), sedangkan fitur Delete menggunakan metode HTTP DELETE dengan dialog modal konfirmasi interaktif. Seluruh antarmuka dirancang responsif, estetik, dan kreatif menggunakan Tailwind CSS.

3. Implementasi Fitur Update & Delete Data Genre

A. Fitur Update Data Genre (/admin/genres/edit/:id)

  • Pengambilan Data Awal: Mengambil data genre spesifik berdasarkan parameter URL (useParams) melalui fungsi getGenreById(id) secara asinkron saat komponen dirender (useEffect).
  • Form Terisi Otomatis: Nilai form.name dan form.description langsung terisi dengan data genre yang ada sehingga admin dapat langsung memperbarui field yang diinginkan.
  • Live Preview Real-Time: Kartu pratinjau langsung memperbarui tampilan badge warna dan teks deskripsi secara instan saat pengguna mengetik perubahan.
  • Pengiriman HTTP PUT: Data yang diubah dikirimkan ke endpoint PUT /api/genres/{id} menggunakan axios.put.
  • Notifikasi Sukses & Auto-Redirect: Menampilkan alert feedback berwarna hijau dan mengarahkan kembali ke daftar genre secara otomatis.

B. Fitur Delete Data Genre (/admin/genres)

  • Tombol Aksi Terpadu: Setiap baris pada tabel genre dilengkapi tombol Edit (warna indigo) dan tombol Hapus (warna merah).
  • Modal Konfirmasi Aman: Saat tombol Hapus diklik, muncul dialog modal yang menanyakan kepastian penghapusan beserta nama genre terkait untuk mencegah kesalahan tidak sengaja.
  • Pengiriman HTTP DELETE: Menjalankan fungsi deleteGenre(id) yang mengirimkan permintaan DELETE /api/genres/{id} ke server API dan langsung memutakhirkan state tabel tanpa reload browser.

4. Implementasi Fitur Update & Delete Data Author

A. Fitur Update Data Author (/admin/authors/edit/:id)

  • Pre-filled Form: Mengisi nilai awal nama lengkap penulis, negara asal (kewarganegaraan), dan biografi dari pemanggilan getAuthorById(id).
  • Pilihan Cepat Kewarganegaraan: Tombol pintas (*chips*) negara populer (Indonesia, Jepang, Inggris, Amerika Serikat) mempermudah admin mengganti asal negara dengan satu klik.
  • Live Preview Kartu Penulis: Menampilkan kartu profil lengkap dengan avatar inisial bergradien warna yang disesuaikan secara real-time.
  • Pengiriman HTTP PUT: Mengirimkan pembaruan data pengarang ke endpoint PUT /api/authors/{id} menggunakan Axios.

B. Fitur Delete Data Author (/admin/authors)

  • Tombol Hapus & Edit pada Tabel: Setiap pengarang memiliki tombol aksi untuk navigasi ke form edit atau memicu modal hapus.
  • Modal Peringatan: Pop-up konfirmasi yang jelas menampilkan nama penulis yang akan dihapus.
  • Pengiriman HTTP DELETE: Menjalankan deleteAuthor(id) via DELETE /api/authors/{id} dan menyinkronkan data secara reaktif.

5. Cuplikan Kode Utama (Update & Delete)

1. Operasi Update via HTTP PUT (Axios)
Mengirimkan perubahan data ke endpoint PUT dan memperbarui state: 
// src/services/api.js - Fungsi updateGenre
export const updateGenre = async (id, genreData) => {
  try {
    const response = await apiClient.put(`/genres/${id}`, genreData);
    if (response.data && response.data.data) {
      return { data: response.data.data, source: 'api' };
    }
  } catch (err) {
    console.warn('Backend API offline, update secara lokal:', err.message);
  }
  // Pembaruan data pada penyimpanan lokal sebagai fallback
  const current = getStoredData('app_genres', INITIAL_GENRES);
  const updatedList = current.map((g) => (String(g.id) === String(id) ? { ...g, ...genreData } : g));
  setStoredData('app_genres', updatedList);
  return { data: { id, ...genreData }, source: 'local' };
};
2. Operasi Delete via HTTP DELETE (Axios)
Menghapus data di server backend dan memperbarui state komponen: 
// src/services/api.js - Fungsi deleteGenre
export const deleteGenre = async (id) => {
  try {
    await apiClient.delete(`/genres/${id}`);
  } catch (err) {
    console.warn('Delete via API gagal, menghapus dari lokal:', err.message);
  }
  const current = getStoredData('app_genres', INITIAL_GENRES);
  const updated = current.filter((g) => String(g.id) !== String(id));
  setStoredData('app_genres', updated);
  return true;
};

// Handler Hapus di Component dengan Modal Konfirmasi
const handleDelete = async () => {
  if (!deleteModal.item) return;
  await deleteGenre(deleteModal.item.id);
  setGenres((prev) => prev.filter((g) => g.id !== deleteModal.item.id));
  setNotification({ type: 'success', message: `Genre "${deleteModal.item.name}" berhasil dihapus.` });
  setDeleteModal({ isOpen: false, item: null });
};
