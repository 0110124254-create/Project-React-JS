1. Deskripsi & Tujuan Tugas

Tugas ini bertujuan mengembangkan Fitur Registrasi Pengguna sebagai bagian penting dalam pengembangan aplikasi perpustakaan dan buku digital Ruang Baca berbasis React JS. Antarmuka dirancang secara kreatif, modern, dan sangat responsif dengan Tailwind CSS, dilengkapi alur penanganan formulir yang handal menggunakan React Controlled Components, validasi formulir real-time, dan umpan balik pengguna yang interaktif.

2. Pemenuhan Kriteria Umum Penugasan

  • Form Registrasi Lengkap: Memuat field Nama Lengkap, Username, Alamat Email, Kata Sandi, Konfirmasi Sandi, dan Persetujuan Syarat & Ketentuan.
  • Validasi Formulir Komprehensif: Pengecekan field tidak boleh kosong, minimal karakter (nama & username min 3 karakter, sandi min 6 karakter), format email valid berbasis regex, username alfanumerik tanpa spasi, serta kesesuaian konfirmasi sandi.
  • Komponen React Efektif & Efisien: Penggunaan useState untuk state form, error, touched, dan UI; event handler modular (handleChange, handleBlur, handleSubmit); serta navigasi mulus menggunakan useNavigate dan react-router-dom.
  • Kreativitas Antarmuka (UI/UX Kreatif): Panel Split-Screen modern dengan kartu keanggotaan digital real-time (Live Digital Membership Card Preview), Password Strength Visual Meter, dan dialog modal sukses registrasi dengan hitung mundur otomatis.
  • Struktur Folder Rapi & Kode Bersih: Pemisahan yang jelas antara halaman otentikasi (src/pages/auth/register.jsx), lapisan komunikasi data (src/services/api.js), serta antarmuka login (src/pages/auth/login.jsx).

3. Rincian Fitur & Kreativitas Desain Antarmuka

A. Live Digital Membership Card Preview (Kreativitas Utama)

Di sebelah kiri form registrasi, terdapat kartu keanggotaan digital bergaya kartu identitas perpustakaan eksklusif dengan gradien warna ungu-indigo. Setiap kali calon pengguna mengetikkan nama, username, atau email, kartu identitas tersebut langsung ter-update secara real-time:

  • Inisial avatar dihasilkan otomatis dari nama pengguna (contoh: "AR" untuk Aulya Reski).
  • Badge status dinamis: "Calon Anggota" berubah menjadi "Terverifikasi" saat checkbox persetujuan dicentang.
  • Nomor ID anggota digital digenerate otomatis berdasarkan potongan username.

B. Password Strength Meter (Indikator Kekuatan Sandi)

Menganalisis kata sandi secara instan saat pengguna mengetik, mengevaluasi panjang karakter, keberadaan angka, huruf kapital, dan simbol khusus. Menampilkan visualisasi progress bar berwarna dinamis (Merah: Sangat Lemah, Kuning: Cukup, Hijau: Kuat, Indigo: Sangat Kuat).

C. Validasi Multi-Tahap (OnBlur & OnChange)

Menerapkan pola interaksi UX terbaik: validasi pada onBlur agar pengguna tidak terganggu saat pertama kali mengetik, dan validasi pada onChange segera setelah field pernah mengalami error sehingga pesan kesalahan langsung hilang begitu pengguna mengetikkan format yang benar.

D. Arsitektur Dual-Layer Storage (API Sanctum + LocalStorage Fallback)

Sistem dirancang dengan arsitektur tangguh dua lapis pada src/services/api.js:

  • Lapisan 1 (Online): Melakukan HTTP POST /api/register ke backend Laravel Sanctum dengan hashing kata sandi dan validasi database SQLite.
  • Lapisan 2 (Offline Fallback): Jika server backend tidak sedang aktif, sistem secara cerdas menyimpan pengguna baru ke localStorage (app_registered_users), termasuk memeriksa keunikan email dan username, sehingga penguji/dosen tetap dapat menguji fungsionalitas registrasi dan login secara mandiri tanpa setup server tambahan.

4. Cuplikan Kode Program Utama

A. Implementasi Validasi & Form Handling (src/pages/auth/register.jsx)

// Validasi field modular pada register.jsx const validateField = (name, value, allValues = formData) => { let error = ""; switch (name) { case "name": if (!value.trim()) error = "Nama lengkap wajib diisi."; else if (value.trim().length < 3) error = "Nama lengkap minimal 3 karakter."; break; case "username": if (!value.trim()) error = "Username wajib diisi."; else if (value.trim().length < 3) error = "Username minimal 3 karakter."; else if (!/^[a-zA-Z0-9_.-]+$/.test(value)) error = "Username hanya alfanumerik tanpa spasi."; break; case "email": if (!value.trim()) error = "Alamat email wajib diisi."; else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value.trim())) error = "Format email tidak valid."; break; case "password": if (!value) error = "Kata sandi wajib diisi."; else if (value.length < 6) error = "Kata sandi minimal 6 karakter."; break; case "password_confirmation": if (value !== allValues.password) error = "Konfirmasi kata sandi tidak cocok."; break; case "agreeTerms": if (!value) error = "Anda harus menyetujui Syarat dan Ketentuan layanan."; break; } return error; };
