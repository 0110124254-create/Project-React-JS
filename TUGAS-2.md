# Tugas 2 — Layouting and Routing serta Styling

## Materi

- `Layouting and Routing.pdf`
- `2. Styling.pdf`

## Implementasi

1. Menambahkan routing dengan React Router untuk halaman Beranda (`/`), Team (`/team`), dan Contact (`/contact`).
2. Mengelompokkan halaman di bawah layout bersama. Header dan Footer digunakan di semua halaman melalui `Outlet`.
3. Menambahkan halaman fallback untuk alamat yang tidak dikenali.
4. Memberi gaya pada navigasi: tautan aktif dan hover memiliki penanda visual, fokus keyboard terlihat, serta menu tetap bisa dibuka pada layar kecil.

## Menjalankan proyek

Di Windows PowerShell, buka folder proyek lalu jalankan:

```powershell
npm.cmd run dev
```
