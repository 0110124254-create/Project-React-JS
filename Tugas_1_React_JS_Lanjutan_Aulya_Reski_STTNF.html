1. Ringkasan Tugas

Pada tugas ini, mahasiswa diinstruksikan untuk membangun fitur Read (menampilkan daftar data) dan Create (menambahkan data baru) untuk entitas Genre dan Author (Penulis) pada antarmuka Admin aplikasi toko buku dan perpustakaan berbasis React JS.

Implementasi menggunakan pustaka Axios dengan pendekatan pemrograman Asynchronous (async/await) untuk berkomunikasi dengan REST API backend Laravel (booksales-api). Antarmuka pengguna (UI) dirancang secara kreatif dan profesional dengan Tailwind CSS dan Flowbite Design System, dilengkapi fitur Live Preview dan penyimpanan cadangan (offline fallback) yang tangguh.

3. Implementasi Fitur Data Genre (Kategori Buku)

A. Fitur Read Genre (/admin/genres)

  • Asynchronous Data Fetching: Memanggil fungsi getGenres() saat komponen pertama kali dimuat menggunakan hook useEffect. Data diperoleh dari endpoint GET /api/genres.
  • Filter & Pencarian Real-Time: Dilengkapi kolom pencarian yang memfilter daftar genre secara instan tanpa perlu reload halaman berdasarkan nama maupun deskripsi.
  • Tampilan Tabel Elegan: Setiap genre ditampilkan dengan nomor urut, badge warna dinamis (indigo, purple, blue, emerald, amber, rose), deskripsi ringkas, dan tanggal terdaftar.
  • Status Bar Sumber Data: Menampilkan indikator real-time apakah data terhubung langsung ke Live Server API atau menggunakan Offline Local Cache.
  • Aksi Hapus dengan Modal Konfirmasi: Dilengkapi tombol hapus dengan pop-up dialog konfirmasi agar tidak terjadi penghapusan tidak sengaja.

B. Fitur Create Genre (/admin/genres/create)

  • Controlled Input Form: Nilai formulir dikelola melalui state React (form.name dan form.description).
  • Pengiriman Asynchronous: Mengirim payload data via axios.post('/genres', payload) dengan penanganan status loading saat tombol ditekan.
  • Fitur Nilai Tambah (Live Preview): Menyediakan pratinjau langsung kartu badge genre secara visual ketika pengguna mengetik nama genre.
  • Feedback & Auto-Redirect: Menampilkan banner alert sukses berwarna hijau dan mengalihkan pengguna kembali ke halaman tabel secara otomatis.

4. Implementasi Fitur Data Author (Penulis Buku)

A. Fitur Read Author (/admin/authors)

  • Asynchronous Data Fetching: Mengambil seluruh data pengarang dari endpoint GET /api/authors menggunakan Axios dengan penanganan try-catch.
  • Profil Pengarang Menarik: Setiap baris tabel dilengkapi avatar inisial dengan latar belakang gradien warna-warni yang dihasilkan otomatis dari nama penulis.
  • Badge Kewarganegaraan: Menampilkan negara asal pengarang dengan ikon globe dan badge elegan.
  • Pencarian Cepat: Dapat mencari penulis berdasarkan nama lengkap, negara, atau cuplikan biografi.

B. Fitur Create Author (/admin/authors/create)

  • Formulir Lengkap: Input nama lengkap penulis (wajib), negara asal/kewarganegaraan, dan biografi atau riwayat singkat pengarang.
  • Pilihan Cepat (Quick Chips): Tombol pintas untuk memilih negara populer (Indonesia, Jepang, Inggris, Amerika Serikat) hanya dengan 1 klik.
  • Live Preview Profil: Kartu avatar gradien dan format tampilan penulis dirender secara real-time saat pengguna mengetik.
  • Validasi & Notifikasi: Validasi client-side memastikan kolom nama terisi sebelum request POST dikirim.

5. Cuplikan Kode Utama (Asynchronous & Axios)

Contoh Pemanggilan Axios GET (Read Data Genre)
Mengambil data dari server API secara asinkron dan memperbarui state komponen: 
// src/services/api.js & src/pages/admin/genres/index.jsx
export const getGenres = async () => {
  try {
    const response = await apiClient.get('/genres');
    if (response.data && response.data.data) {
      setStoredData('app_genres', response.data.data);
      return { data: response.data.data, source: 'api' };
    }
  } catch (err) {
    console.warn('Fallback ke penyimpanan lokal:', err.message);
  }
  return { data: getStoredData('app_genres', INITIAL_GENRES), source: 'local' };
};
Contoh Pemanggilan Axios POST (Create Data Genre)
Mengirim payload data input dari pengguna menggunakan metode POST: 
const handleSubmit = async (e) => {
  e.preventDefault();
  if (!form.name.trim()) return;

  setLoading(true);
  try {
    const res = await createGenre({
      name: form.name.trim(),
      description: form.description.trim() || null,
    });
    setSuccess({ message: `Genre "${res.data.name}" berhasil ditambahkan!` });
    setTimeout(() => navigate('/admin/genres'), 1400);
  } catch (err) {
    setError('Gagal menambahkan data genre.');
  } finally {
    setLoading(false);
  }
};
